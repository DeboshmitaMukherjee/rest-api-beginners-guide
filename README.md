## Example

A simple REST API request might look like:

~~~http
GET /users/123
~~~

The API could return:

~~~json
{
  "id": 123,
  "name": "John Smith",
  "email": "john@example.com"
}
~~~

The request asks the API to retrieve information about a specific user.
